SNAPPOP — CUTE PHOTOBOOTH

CARA MENJALANKAN
1. Extract file ZIP ini.
2. Cara paling mudah untuk mengaktifkan kamera: upload folder ini ke GitHub Pages / Netlify, lalu buka alamat HTTPS-nya.
3. Bisa juga jalankan secara lokal memakai VS Code + ekstensi Live Server, lalu klik "Open with Live Server".
4. Buka index.html. Untuk akses kamera, browser biasanya mensyaratkan HTTPS atau localhost; membuka file langsung (file://) bisa membuat kamera tidak tersedia.
5. Klik "Buka Kamera" dan izinkan akses kamera. Jika ditolak, klik ikon gembok/pengaturan situs di browser lalu izinkan Camera.
6. Jika kamera gagal, gunakan "Upload Foto" untuk memilih gambar dari perangkat.

FITUR
- 12 frame lucu
- Kamera dan hitung mundur
- Upload foto dari perangkat
- Pengaturan brightness, contrast, saturation, warm, soft, dan B&W
- Hasil diekspor sebagai PNG dengan dimensi mengikuti foto sumber
- Galeri sesi sementara; unduh hasil untuk menyimpannya permanen

CATATAN KUALITAS
Web ini tidak bisa menambahkan detail yang tidak ada pada foto sumber. Hasil tidak di-upscale agar tidak membuat gambar makin pecah. Untuk hasil paling jernih, gunakan kamera dengan pencahayaan cukup, bersihkan lensa, dan pilih resolusi kamera tertinggi yang tersedia. Kualitas kamera juga bergantung pada perangkat/browser.

PRIVASI
Foto diproses secara lokal di browser dan tidak dikirim ke server oleh kode ini. Galeri mini hanya tersimpan selama halaman tetap terbuka. Simpan/unduh foto untuk menyimpan permanen.
